# Money Tracker (Desktop)

Локальное десктопное приложение для учёта доходов и расходов. Работает без сервера и без Telegram: данные хранятся на компьютере в зашифрованном виде, доступ — по логину и паролю.

## Возможности

- Несколько локальных пользователей, создание аккаунта при старте
- Журнал доходов/расходов/накоплений, быстрый текстовый ввод, фильтры, Excel
- Графики, месячный план (бюджет), состояние счетов со снимками остатков
- Категории, настройки расчётного периода (зарплата/аванс)
- Напоминание «зафиксировать остатки» в центр уведомлений Windows
- Бекап MTBAK2 (AES-256-GCM) и импорт старых бекапов MTBAK1 из серверного приложения

## Стек

Electron + React + TypeScript, SQLite (`better-sqlite3`), Argon2id + AES-256-GCM.

## Разработка

```bash
pnpm install
pnpm -r --filter=./packages/* build
pnpm test
pnpm dev
```

## Сборка Windows

```bash
pnpm build
pnpm dist:win
```

Установщик появится в `apps/desktop/release/`.

## CI

- **Тесты** — на каждый push и pull request
- **Release** — при merge в `master`: тесты, сборка `.exe`, GitHub Release с notes из слитого PR

## Безопасность

- Пароль не хранится: Argon2id-хэш + ключ шифрования базы из пароля (scrypt)
- Файл `user-<id>.db.enc` на диске всегда зашифрован; расшифрованная сессия живёт только пока пользователь вошёл
